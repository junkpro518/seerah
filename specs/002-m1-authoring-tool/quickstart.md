# Quickstart — م١ أداة الإدخال/المحرّر (تشغيل وتحقّق)

> دليل تشغيل/تحقّق. لا كود تنفيذي هنا (يأتي في tasks/implement). **لا يمسّ هذا المسار السحابي؛ E2E على مكدّس محلي زائل.**

## المتطلبات
- Node 20 + مدير حزم (pnpm/npm).
- Docker (لمكدّس Supabase المحلي للاختبار).
- Supabase CLI (مرتبط بمشروع م٠ السحابي للتشغيل الحقيقي؛ ومحلي للاختبار).

## متغيّرات البيئة
```
NEXT_PUBLIC_SUPABASE_URL=...            # عام (متصفّح)
NEXT_PUBLIC_SUPABASE_ANON_KEY=...       # عام (متصفّح) — RLS يفرض الصلاحيات
SUPABASE_SERVICE_ROLE_KEY=...           # ⚠️ خادم فقط — ممنوع في المتصفّح
```

## التشغيل (تطوير)
```bash
pnpm install
pnpm dev        # Next.js (App Router) — واجهة RTL عربية
```

## الاختبار
```bash
# وحدة (Vitest + RTL)
pnpm test:unit

# E2E (Playwright) على مكدّس Supabase محلي زائل (لا السحابي)
supabase start && supabase db reset   # يطبّق ترحيلات م٠ + seed محليًا
pnpm test:e2e
```

## سيناريوهات تحقّق (تُغطّى بـ E2E للمسارات الحرجة)

1. **دخول + 2FA (US1):** سجّل دخولًا → تُحجب مسارات `(admin)` (aal1) → سجّل TOTP → احفظ الرموز الاحتياطية → تحقّق → بلغت aal2 → وصلت. محاولة حفظ بـ aal1 تُرفض برسالة واضحة. (يحقّق SC-001/002.)
2. **استعادة 2FA:** بفقد الجهاز، استخدم رمزًا احتياطيًا → أعد التسجيل؛ وبفقد الرموز، المدير يعيد التعيين. (FR-005.)
3. **محرّر المعلومة (US2):** أنشئ معلومة بحاوية واحدة + استشهاد من مصدر approved + درجة → احفظ مسودة → قدّمها. جرّب: حاويتين (يُمنع)، تقديم بلا استشهاد (يُمنع)، درجة تتطلّب مصدر حكم بلا مصدر (يُمنع) — رسائل استخدام لا أخطاء خام. (SC-003/004.)
4. **السرد الغني (US3):** اكتب فقرة، أدرج عقدتي claimRef → تظهر `[1]`,`[2]`؛ اعكس الترتيب → يتحدّث الترقيم؛ احفظ → body_plain متزامن؛ الهايلايت بألوان الدرجات. (SC-005.)
5. **القفل التفاؤلي:** افتح صفًّا في تبويبين، احفظ الأول، ثم احفظ الثاني → تحذير تعارض، لا كتابة فوق. (FR-030.)
6. **سير المراجعة (US4):** بدور كل طبقة، يظهر الانتقال المسموح فقط؛ محاولة انتقال ممنوع تُرفض من م٠. (SC-006.)
7. **المصادر (US5):** اقترح مصدرًا (proposed، غير قابل للاستشهاد) → المدير يعتمده (approved) → صار قابلًا للربط + ظهر في التدقيق.
8. **عزل الأمان:** غير المدير لا يرى التدقيق/الطابور (SC-007)؛ فحص الحزمة لا يُظهر service role (SC-008)؛ لا تغيير مخطط (SC-009).

## Definition of Done (م١)
- كل القصص P1 (دخول+2FA، محرّر المعلومة، السرد الغني) تعمل وتُغطّى E2E.
- كل سيناريوهات التحقّق أعلاه تمرّ.
- صفر service role في حزمة العميل؛ صفر تغيير مخطط م٠؛ كل كتابة تتطلّب aal2.
- استضافة على VPS/Coolify تعمل.
