# Quickstart — دليل التحقق والتشغيل: م٠ نواة قاعدة البيانات

> دليل تشغيل/تحقق فقط. تفاصيل التنفيذ في `tasks.md` وملفات migration. كل الأوامر تُنفَّذ من جذر المشروع.

## المتطلبات المسبقة

- Node 22 · Supabase CLI 2.75 · Git · **Docker يعمل** (مختبر اختبار محلي زائل — دستور v1.0.1).
- **من المالك (قبل التنفيذ فقط):** `supabase login` للحساب الثاني + معرّف المشروع السحابي (Settings → General → Reference ID).
- موافقة المالك على plan + tasks (لا implement قبلها).

## حلقة التطوير (TDD، محلي زائل)

```bash
# مرة واحدة
supabase init
supabase start                 # يشغّل Postgres محلي + يطبع المفاتيح (أول مرة يحمّل الصور)

# حلقة كل مهمة (أحمر → أخضر)
supabase test db               # (أحمر) بعد كتابة الاختبار، يجب أن يفشل
# ... اكتب الـ migration ...
supabase db reset              # يطبّق الترحيلات + البذرة على المحلي
supabase test db               # (أخضر) يجب أن ينجح
git add ... && git commit ...  # commit لكل خطوة (قرار ٢٠)
```

## النشر للسحابي (بعد نجاح الاختبارات + موافقة)

```bash
supabase link --project-ref <REF>   # الحساب الثاني (يُطلب من المالك)
supabase db push                    # يدفع الترحيلات المعتمدة للسحابي — السحابي لا يُصفَّر إطلاقًا
```
> **ممنوع:** تعديل المخطط عبر لوحة Supabase أو أدوات MCP (تشير للحساب الخطأ) — Git مصدر الحقيقة (FR-038).

## سيناريوهات التحقق النهائية (تُثبت نجاح م٠)

تُنفَّذ بـ `supabase test db` وكلها تمرّ خضراء:

1. **بوابة المراجعة (US1، مدرك للطبقة):** الهيكل لا يقفز draft→published (شرعي ثم تحريري ثم نشر)، والترجمة تحريرية فقط ولا تُنشر إلا والهيكل published — حتى للمدير؛ anon يرى "الظاهر" فقط (هيكل published AND ترجمة published). → `05_state_machine`, `07_rls`
2. **التوثيق (US2):** claim بلا استشهاد يُرفض؛ "حكم" بلا grading_source يُرفض. → `03_constraints`
3. **التدقيق (US3):** تعديل حرف تشكيل يُنتج صف تدقيق؛ UPDATE/DELETE على audit_log يفشل حتى لـ admin. → `06_audit`
4. **اللغات (US4):** (entity_id,lang) فريد؛ ترجمة غير منشورة لا تظهر؛ claim مشترك بترقيم مشتق لكل لغة. → `04_translations`
5. **السلامة (US5):** الحذف يضبط deleted_at (لا DELETE)؛ claim بعدد حاويات ≠ 1 يُرفض؛ body_plain مشتق. → `03_constraints`, `04_translations`
6. **الأدوار (US6):** author لا ينشر؛ الكتابة تتطلب aal2. → `07_rls`
7. **القوائم المرجعية:** الأكواد والتسميات العربية مبذورة. → `01_lookups`
8. **الخطّاف (US7):** حدث مهم → صف في notification_outbox. → `08_outbox`
